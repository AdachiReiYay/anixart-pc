# Anixart для ПК

Неофициальный клиент Anixart для Windows x64. Каталог, закладки, лента и просмотр серий в одном приложении.

**[Скачать Anixart для ПК 3.10.3](https://github.com/AdachiReiYay/anixart-pc/releases/tag/v3.10.3)** · предварительная версия · ZIP, 50,8 МиБ

## Запуск

1. В списке файлов релиза скачайте `AnixartPC-3.10.3-Portable-Windows-x64.zip`.
2. Распакуйте архив целиком и запустите `AnixartPC.exe`. Храните папку `Tools` рядом с программой.

Библиотеки .NET входят в сборку. Встроенный плеер использует [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

## Возможности

- Каталог, поиск по `Ctrl+F`, подборки и расписание в «Обзоре».
- Выбор озвучки, источника и серии рядом с плеером. Панель серий можно свернуть.
- Закладки, история просмотра, профиль и лента.
- Вход по QR-коду с телефона или по логину и паролю.

При отправке комментария или реакции возможны ответы Anixart с кодами `402` и `1`. Доступность видео зависит от источника.

Название и графические материалы Anixart принадлежат их правообладателям. Лицензии сторонних компонентов входят в архив.
